2-CASTANEA的层级结构

Read inputs and initialization

1)read_ini : ini file (species)

2)Initglobal

Each year :

1) read_parcelle (stand informations – LAI, leaf N, age)

2) init_CheneSessile

3) initannuelle

4) initgeo (site)

Each day :

1) initjour

2) choix_georad (leaf, trunk, soil optical radiative properties)

3) calc_LIDF

Each hour (or minute or seconds) :

1) meteoglobal (daylength)

2) meteohoraire

3) calc_skyl (%diffuse radiation)

4) coef_rayonnement (radiative balance, absorbed radiation, reflectance, transmittance)

5) Interception (precipitation)

6) coef_rayonnement_IRT

7) boucle_one (-> boucle_LAI (layers) -> photorbana2 (photosynthesis)
